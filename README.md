# TravelApp
A cross-platform mobile travel application built with **Flutter**.  
This project demonstrates clean UI design, responsive layouts, modular widget structure, and core Flutter development principles.

---

## Overview
TravelApp is a sample travel-themed application that showcases destinations, images, and UI components often used in modern mobile apps.  
The goal of the project is to demonstrate:

- Flutter UI/UX fundamentals  
- Navigation & screen structuring  
- Asset management (images, icons, fonts)  
- Cross-platform build configuration  
- Clean and organized project architecture  

The project compiles on **Android**, **iOS**, **Web**, **macOS**, **Windows**, and **Linux** (Flutter multi-platform support enabled).

---

## Features
- Clean, minimal, travel-themed UI  
- Destination listings (images, descriptive sections)  
- Reusable Flutter widgets  
- Cross-platform support through Flutter  
- Responsive layouts  
- Folder-based modular code structure  

---

## Tech Stack
- **Flutter** (Dart)  
- **Material Design Components**  
- **Platform Support:** Android, iOS, Web, Windows, Linux, macOS
